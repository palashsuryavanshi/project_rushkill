**Goal:** Remove the remaining frame-cost and load-time debt on low-end hardware — near-zero per-frame React churn, fewer draw calls, cheaper water, vendor chunk splits, a low-graphics preset — with zero gameplay or map changes.

**Architecture:** Stay on Vite + React + Three.js; fix costs at their exact sources (engine notifier, static-geometry bake, ocean mesh, build config). No engine internals change shape; no gameplay code changes.

**Tech Stack:** Vite 8, React 19, Three.js r187 (`BufferGeometryUtils` from `three/examples/jsm/utils/BufferGeometryUtils.js`), TypeScript, Tailwind 4.

**Spec:** `docs/superpowers/specs/2026-11-05-performance-hardening-design.md` — read it before this plan; it carries the intent and non-goals.

## Global Constraints
- No gameplay, balance, or map-design changes. Visual preservation: merged map must be pixel-identical in the named reference views (bow helipad, walkway crate, cabin); only segment density and fps cost may move.
- No new runtime dependencies. `motion` must be *removed*, nothing added.
- FPS readout: **on by default** (owner decision 2026-11-05), hidden via settings toggle, never React-updated faster than 1 Hz.
- Low-graphics preset applies on next match restart (renderer/context cannot be safely recreated mid-match).
- Production build must contain no `console.*` calls (vite `esbuild.drop`).
- Every task ends with `node node_modules/vite/bin/vite.js build` succeeding and a commit.

## Review Focus
1. **Merged-geometry mis-bucketing silently drops or double-renders map meshes** — pinned to Task 4: test asserts total mesh count dropped to expected merged-set size and zero colliders lost; screenshot check of 3 named views.
2. **Settings preset toggles mid-match do nothing (or break the live renderer)** — pinned to Task 6: preset is read only at engine construction; UI explicitly notes "Applies on next match"; test toggles while paused and verifies renderer flags unchanged until restart.
3. **FPS readout re-introduces per-frame setState** — pinned to Task 5: readout is 1 Hz; code review asserts only a 1 Hz interval writes to state; no per-frame notify added.
4. **notifyStats shallow-compare swallows discrete hp/ammo changes** — pinned to Task 2: unit-style node check of the compare helper (hp diff fires; identical doesn't; reloadProgress quantization keeps 0.01 steps).
5. **Ocean at 32×32 flattens bow/stern wake foam** — pinned to Task 3: same amplitude formula kept verbatim; visual check of bow helipad view against current build.
6. **Production build still ships console calls** — pinned to Task 1: `grep -c "console\." dist/assets/*.js` returns 0 after vite `esbuild.drop` is set.

- [ ] **Step 1 (Review Focus #4):** Create `src/game/notifyGate.ts`:
```ts
import { PlayerStats } from './types';

// Shallow compare of the stats payload, ignoring nothing — every field is meaningful.
// reloadProgress is quantized to 0.01 steps by the caller so micro-float churn doesn't spam.
export function statsChanged(a: PlayerStats | null, b: PlayerStats): boolean {
  if (!a) return true;
  return (
    a.hp !== b.hp || a.maxHp !== b.maxHp || a.ammo !== b.ammo ||
    a.reserveAmmo !== b.reserveAmmo || a.isReloading !== b.isReloading ||
    a.reloadProgress !== b.reloadProgress || a.isAds !== b.isAds ||
    a.score !== b.score || a.kills !== b.kills || a.deaths !== b.deaths ||
    a.streak !== b.streak || a.highestStreak !== b.highestStreak ||
    a.headshots !== b.headshots || a.shotsFired !== b.shotsFired ||
    a.shotsHit !== b.shotsHit || a.speed !== b.speed ||
    a.isSliding !== b.isSliding || a.isGrounded !== b.isGrounded
  );
}

export interface LastMinimap { x: number; z: number; angle: number }
// Quantized compare: skip if player moved < 0.05u and angle changed < 0.01 rad
export function minimapChanged(last: LastMinimap | null, x: number, z: number, angle: number): boolean {
  if (!last) return true;
  const dx = last.x - x, dz = last.z - z;
  let da = Math.abs(last.angle - angle);
  if (da > Math.PI) da -= Math.PI * 2;
  return dx * dx + dz * dz > 0.0025 || Math.abs(da) > 0.01;
}
```

- [ ] **Step 2:** engine.ts — implement:
```ts
public graphicsTierApplied: 'high' | 'low' = 'high';
public applyGraphicsPreset(preset: 'auto' | 'high' | 'low'): void {
  if (this.isSoftwareGl) return; // software path already low
  let tier: 'high' | 'low' = 'high';
  if (preset === 'low') tier = 'low';
  else if (preset === 'auto') {
    const dm = (navigator as unknown as { deviceMemory?: number }).deviceMemory ?? 8;
    const hc = navigator.hardwareConcurrency ?? 8;
    tier = dm < 4 || hc <= 4 ? 'low' : 'high';
  }
  if (tier === 'low') {
    this.renderer?.setPixelRatio(1);
    if (this.renderer) this.renderer.shadowMap.enabled = false;
    // sunLight created in initScene after this point — gate castShadow there via this.graphicsTierApplied
    (this as { MAX_PARTICLES: number }).MAX_PARTICLES = 32;
    (this as { MAX_TRACERS: number }).MAX_TRACERS = 16;
    this.graphicsTierApplied = 'low';
  }
}
```
(Particles/tracers fields are currently `private readonly MAX_*` — change `readonly` to mutable `private MAX_*`.
